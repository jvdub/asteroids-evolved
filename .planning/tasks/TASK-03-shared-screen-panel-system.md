# TASK-03: Shared Screen Panel System

## Objective
Create a unified panel/card layout system for non-gameplay screens to replace dated per-screen styling.

## Scope
- Apply consistent panel wrappers to instructions, high scores, options, and about screens.
- Standardize headings, body text widths, and content spacing.
- Preserve existing IDs/events so behavior remains unchanged.

## Deliverables
- Updated `index.html` non-gameplay screen markup wrappers/classes.
- Updated `style/main.css` shared panel system styles.

## Acceptance Criteria
- Non-gameplay screens have consistent structure and polish.
- Existing event bindings still work without JS logic breakage.
- `npm run build` and `npm run check:static-arch` pass.
